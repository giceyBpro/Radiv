API Dosimétrie RIV

Pour envoyer une requête à l'API et lire la réponse.

Endpoints

  • GET /api/config : radiopharmaceutiques, options de cures.
  • POST /api/calculate : calcule les durées de restriction.
  • GET /api/public-config : clé publique reCAPTCHA, niveau et durée de conservation de la journalisation.
  • POST /api/contact : envoi d'un message de contact.
  • GET /health : disponibilité du service.

Payload — POST /api/calculate

{
  "calculation_mode": "sfmn",
  "isotope_code": "iode131_25_fixation",
  "dose_rate": 9.9,
  "patient_size_cm": 150,
  "user_period_days": null,
  "user_hours_1": null,
  "user_distance_1": null,
  "user_hours_2": null,
  "user_limit": null,
  "benign_activity_mbq": null,
  "benign_fixation_pct": null,
  "cure_count": 1
}

Règles

  • Standard : dose_rate + patient_size_cm.
  • iode131_benin : benign_activity_mbq + benign_fixation_pct (%) ; dose_rate ignoré.
  • non_defini : user_period_days strictement positif obligatoire.
  • cure_count : psma_177lu (1/4/6), lutetium177_net (1/4), sinon 1 uniquement.
  • cure_count > 1 : limite répartie sur les cures, sauf transport_commun (non cumulé).

Réponse (succès)

{
  "ok": true,
  "calculation_mode": "sfmn",
  "selected": { "api_code": "...", "label": "..." },
  "cure_count": 1,
  "computed_dose_rate": 9.9,
  "effective_days": 0.67,
  "effective_hours": 16,
  "errors": [],
  "recommendations_days": {
    "conjoint_plus_60": 0,
    "conjoint_moins_60": 0,
    "conjointe_enceinte": 0,
    "transport_commun": 0,
    "enfant_moins_3_ans": 0,
    "enfant_3_11_ans": 0,
    "collegues_travail": 0,
    "scenario_utilisateur": null
  },
  "rows": [
    { "audience_code": "conjoint_plus_60", "label": "...", "condition": "...", "value": 0 }
  ]
}

rows reprend les valeurs de recommendations_days avec un libellé et un texte de condition prêts à afficher pour chaque scénario.

En mode SFMN, rows n'est pas renvoyé au même niveau de fiabilité ; sfmn_source contient alors uniquement url en usage normal.

Réponse (erreur de validation)

{
  "ok": false,
  "error": { "code": "VALIDATION_ERROR", "message": "...", "reason": "..." },
  "errors": ["..."]
}
