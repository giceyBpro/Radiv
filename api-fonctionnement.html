Fonctionnement de l'API Dosimétrie RIV

Cette page décrit uniquement le contrat d'échange avec l'API (endpoints, champs attendus, formats).

Endpoints

  • GET /api/config : retourne la liste des radiopharmaceutiques et la valeur par défaut.
  • POST /api/calculate : calcule les durées de restriction selon les données envoyées.
  • GET /health : endpoint de supervision (monitoring).
  • GET /api/public-config : renvoie la clé reCAPTCHA publique.
  • POST /api/contact : envoi du message de contact (validation reCAPTCHA côté backend).

Champs attendus (sans caractères spéciaux)

Le payload JSON de POST /api/calculate doit utiliser les clés suivantes :

isotope_code
calculation_mode
dose_rate
patient_size_cm
user_period_days
user_hours_1
user_distance_1
user_hours_2
user_limit
benign_activity_mbq
benign_fixation_pct
cure_count

Les champs à null peuvent être omis du payload. L'API interprète les champs absents comme null.

calculation_mode accepte actuellement local (mode par défaut) et sfmn.

En mode sfmn, le backend soumet les données au formulaire SFMN distant (URL configurée côté serveur), parse la page de résultats HTML puis renvoie les recommandations dans le même format API.

Cas particulier : iode131_benin

Pour isotope_code=iode131_benin, les données attendues ne sont pas les mêmes : vous devez fournir benign_activity_mbq et benign_fixation_pct. Dans ce cas, dose_rate est ignoré car calculé automatiquement par l'API.

Cas particulier : non_defini

Pour isotope_code=non_defini, vous devez fournir user_period_days (strictement positif) en plus de dose_rate, car aucune période effective n'est déduite automatiquement.

Cas particulier : cures répétées

Le champ cure_count est optionnel (valeur par défaut : 1). Il est pris en compte uniquement pour les isotopes suivants : radium223 (1, 4, 6), psma_177lu (1, 4, 6), lutetium177_net (1, 4). Pour les autres isotopes, la valeur effective reste 1.

Formulaire de contact

Payload de POST /api/contact :

{
  "name": "Prénom Nom",
  "email": "adresse@exemple.fr",
  "subject": "Demande",
  "message": "Votre message...",
  "recaptcha_token": "token_google"
}

Réponse de succès :

{ "ok": true }

Exemple de retour de l'API

Réponse type de GET /api/config :

{
  "isotopes": [
    { "api_code": "iode131_25_fixation", "label": "Iode-131-25%-fixation", "periodHours": 16 }
  ],
  "default_isotope_code": "iode131_25_fixation",
  "default_calculation_mode": "local",
  "calculation_modes": ["local", "sfmn"],
  "cure_options_by_isotope": {
    "radium223": [1, 4, 6],
    "psma_177lu": [1, 4, 6],
    "lutetium177_net": [1, 4]
  }
}

{

  "selected": { "api_code": "...", "label": "...", "periodHours": 16, "reference": "...", "remark": "...", "situation": "..." },
  "cure_count": 1,
  "cure_count_allowed": [1],
  "computed_dose_rate": 20,
  "effective_days": 0.66,
  "effective_hours": 16,
  "errors": [],
  "recommendations_days": {
    "conjoint_plus_60": 0,
    "conjoint_moins_60": 0,
    "conjointe_enceinte": 0,

    "enfant_moins_3_ans": 0,
    "enfant_3_11_ans": 0,
    "collegues_travail": 0,

Types de public (clés de recommendations_days) : conjoint_plus_60, conjoint_moins_60, conjointe_enceinte, transport_commun, enfant_moins_3_ans, enfant_3_11_ans, collegues_travail, scenario_utilisateur.

Réponse en cas d'échec de validation :

{
  "ok": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "...",
    "reason": "...",
    "expected_payload": { "common": ["..."], "isotope_specific_required": ["..."] }
  },
  "errors": ["..."]
}

Exemple d'appel

curl -X POST "$RADIOPROTECTION_API_URL/calculate" \
  -H "Content-Type: application/json" \
  -d '{
    "isotope_code": "iode131_25_fixation",
    "calculation_mode": "local",
    "dose_rate": 20,
    "patient_size_cm": 160,
    "user_period_days": null,
    "user_hours_1": null,
    "user_distance_1": null,
    "user_hours_2": null,
    "user_limit": null,
    "benign_activity_mbq": null,
    "benign_fixation_pct": null,
    "cure_count": 4
  }'
