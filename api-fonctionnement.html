Comment utiliser le calculateur Dosimétrie RIV

Cette page explique uniquement les informations utiles pour utiliser le site. Aucun réglage technique n’est nécessaire.

1) Remplir les éléments obligatoires

  • Choisissez le mode de calcul (SFMN ou local).
  • Choisissez le radiopharmaceutique.
  • Renseignez le débit de dose à 1 m et la taille du patient (sauf cas Iode-131 bénin).
  • Pour Iode-131 bénin, renseignez l’activité (MBq) et le taux de fixation (%).

2) (Optionnel) Décrire un scénario personnalisé

Vous pouvez laisser cette partie vide si vous voulez seulement les recommandations standards.

  • Période effective imposée (si nécessaire).
  • Temps à Xm + Distance X.
  • Temps à 1 m + limite dosimétrique.

3) Lancer le calcul

  • Cliquez sur le bouton « Calculer les durées de restriction ».
  • Pendant le calcul, un indicateur d’attente s’affiche.
  • Les durées recommandées apparaissent dans le tableau vert.

4) Partager / imprimer

  • Version imprimable : fiche A4.
  • Version explicative : texte simplifié pour le patient, imprimable et copiable.
