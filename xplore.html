Modèles prêts à importer dans Xplore pour intégrer le calcul RadIV directement dans votre flux de travail.

Vérification données sensibles : ces fichiers ont été contrôlés — ils ne contiennent aucune donnée patient, aucun identifiant nominatif. Ils contiennent uniquement le code auteur (JBOURR), le site source (CMN) et un numéro de référence de questionnaire lié (A10111100209 dans l'insertion automatique) — voir le tableau d'adaptation ci-dessous.

Installation dans Xplore

  1. Dans Xplore, aller dans Administration → Modèles de compte-rendu → Importer.
  2. Importer d'abord le questionnaire QUDEM — Xplore lui attribue un nouveau numéro (ex. A10xxxxxxx).
  3. Importer ensuite l'insertion automatique INSER.
  4. Dans l'INSER importée, ouvrir les propriétés et renseigner le numéro du questionnaire QUDEM attribué à l'étape 2 dans le champ Questionnaire HTML lié.
  5. Associer les deux modèles aux types d'examens souhaités (ex. CS, TT).
